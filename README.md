# Vice City Key Shop

Loja pessoal em modo local. A versão independente está no arquivo **`local-shop.html`**.

## Como abrir no Windows

1. Clique em **Code** → **Download ZIP** neste repositório.
2. Extraia o ZIP para uma pasta do computador.
3. Abra a pasta extraída.
4. Dê dois cliques em **`local-shop.html`**. Ele abre no navegador, sem instalar Node.js, sem Supabase e sem internet para as funções locais.

## O que a versão local faz

- Catálogo de GTA V e GTA VI.
- Estoque local por jogo e plataforma.
- Cadastro manual de códigos que você possui legitimamente.
- Marcação local de códigos como resgatados.
- Histórico de ações.
- Exportação e importação de backup em JSON.
- Links para pesquisar anúncios no Mercado Livre.

## Importante

Esta é uma ferramenta pessoal e local. Os dados ficam no armazenamento do navegador deste computador; limpe os dados do navegador apenas depois de exportar um backup. A compra é demonstrativa: não processa pagamentos, não cria chaves e não ativa jogos em PlayStation, Steam, Xbox ou Rockstar. Para obter uma licença real, use um código legítimo e resgate-o na plataforma oficial correspondente.

O projeto original com React/TanStack continua no repositório; para usar a versão independente, abra **`local-shop.html`** diretamente.
